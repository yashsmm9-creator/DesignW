Mathematics

Quadratic equation

ax² + bx + c = 0
a ≠ 0
x = (-b ± √(b² - 4ac)) / (2a)

Discriminant: Δ = b² − 4ac. Δ determines the type of real roots.

Derivative rules

d(xⁿ)/dx = n·xⁿ⁻¹
 d(c)/dx = 0
 d(u+v)/dx = u' + v'

Machine learning metrics

MSE = (1/n) Σ(yᵢ − ŷᵢ)²
Accuracy = (TP + TN) / (TP + TN + FP + FN)
Precision = TP / (TP + FP)
Recall = TP / (TP + FN)

TP=true positive, TN=true negative, FP=false positive, FN=false negative. Accuracy may be misleading on imbalanced data.
